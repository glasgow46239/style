Using it

Every value on this page comes from one file, tokens.json. Change a colour there and push: the build regenerates be.css and be.js, and every page that links them picks up the change on its next load.

In a page or iframe

<link rel="stylesheet" href="https://glasgow46239.github.io/style/be.css">
<script src="https://glasgow46239.github.io/style/be.js"></script>

In JavaScript

BE.fill('Lib Dem')            // '#FAA61A'  lines, bars, map fills
BE.text('ldem')               // '#9C6B25'  party-coloured text on white
BE.fill('con', {dark: true})  // '#1C7A98'  force the dark-background value
BE.colours(['con','lab','ref'])  // {con:'#05718F', lab:'#CF4545', ref:'#15B6C2'}
BE.name('grn', 'analysis')    // 'the Greens'
BE.signal('negative', 'text') // '#B35A0E'
BE.neutral('grid')            // '#E5E5E5'

Any spelling works: LD, LDem, Lib Dem and Liberal Democrats all resolve to the same party, and so do Datawrapper-style column names such as Con (to 2024 election).

In CSS

.headline { font-family: var(--be-font); color: var(--be-ink); }
.lab-figure { color: var(--be-lab-text); }
.bar.ref { background: var(--be-ref); }
/* or the ready-made classes: be-c-lab (text), be-bg-lab (fill) */

In Python (benma pipeline)

from brand import party_colour
party_colour("Reform")   # '#15B6C2'

Dark backgrounds

Pages stay light unless they say otherwise. Put data-theme="dark" on <html> for a dark page, or data-theme="auto" to follow the reader's system setting. The CSS variables and BE.fill() switch to the dark-background values automatically.

Party colours

Each party has a fill for lines, bars and maps, and a text colour that passes 4.5:1 contrast. Where the fill is already dark enough, the two are the same. Every pair that shares a chart stays distinguishable for readers with red-green colour blindness.

PartyKeyFillText on whiteFill on darkText on dark
  • The SNP and Plaid Cymru never share a chart, so they are allowed to sit closer to each other than to anyone else.
  • Others are a mid grey; Independents are a darker grey, for maps where genuine Independents are split out from the residual vote.
  • Never use party fills for body text. Light fills (Lib Dem, SNP, Reform, Green, Others) are unreadable as text on white.

Positive and negative

For approval ratings, swing and change trackers. Blue and orange stay distinct for every common type of colour blindness and can't be mistaken for Labour red or Green green. Always pair the colour with a sign. Series named Positive, Negative or Unsure (or Approve, Disapprove, Don't know) get these colours automatically, with "Unsure" in neutral grey.

Charts

The house style, carried over from the Datawrapper trackers.

  • Party lines are 2.5px with a 3px border in the background colour, so crossing lines stay separate.
  • The horizontal axis has tick marks and a black (very dark) baseline. The vertical axis has no line, only light gridlines with labels.
  • Label lines directly at their right-hand end, in the party's text colour, rather than using a legend where space allows.
  • Leading party at the top of any list or bar ordering; Others last.
  • Figures use tabular numerals so columns of numbers line up.

Type

IBM Plex Sans for words; Roboto Mono for figures in tables, tiles and history tables. Both are free from Google Fonts and be.css loads them for you. Headings are bold (700) with -0.02em letter-spacing.

small 13Fieldwork 14–16 October. Sample 2,031 GB adults.
figures69.9 20.6 +34.1 −2.3 31.4%
caption 11Source: Britain Elects poll aggregate. Smallest text allowed.
  • Nothing below 11px.
  • Headlines in sentence case.
  • Weights: 400 for text, 600 only for the small capitals of a result line, 700 for headings and key figures.
  • Roboto Mono for figures that sit in columns (tables, tiles). Figures inside running text stay in Plex Sans.

Interface

  • Corners: one radius, 5px (--be-radius), for anything with a corner: buttons, inputs, selects, segmented controls, panels, tiles, legends, dropdowns, drawers. No pills or fully rounded buttons.
  • Data marks stay square (--be-radius-mark, 0): bars, stripes, swatches, legend squares. Switches use a 5px track with a 3px knob.
  • Active state is ink (#1A1A1A) with white text; hover is #F5F5F5; borders are 1px #CCCCCC.
  • Use a dropdown, not a row of pills, once there are more than four or five options.
  • Minimal chrome: hairline borders in the border colour, no shadows, no gradients.
  • Party colour carries identity; interface text stays in the ink colours.

Map panels

One stylesheet, be-map.css, styles the results and history panels on every map (le2026, learchive, Britain Predicts). Link it after be.css; it applies to the existing panel markup. The settings come from the map panel tuner.

Where the panel sits

Set one attribute on the map container. Narrow screens always use the bottom drawer, which carries the same top rule and result line.

  • Panel 290px wide (in rem), 12px inner padding, 5px corners; floating cards get a soft shadow, sidebars a hairline on the map side.
  • A 4px rule in the winner's colour runs across the top. On a gain, its left 20px takes the previous winner's colour.
  • Result line: 11px semibold capitals, short party names, each with its colour square and text colour; "gain from" and "hold" in grey.
  • Ward or seat name 16px bold, -0.02em; council or region 14px grey; 1px #CCCCCC rule beneath.
  • Labels and column headers 11px capitals in #767676, no letter-spacing.
  • Stacked bars: 15px this election, 4px last time, 1px apart, full opacity, white seams between parties.
  • Tables: 21px rows, 13px text, 5px party stripes, party column fitted to the longest name, faint #F5F5F5 row dividers, no rule under the headers.
  • History tables: the latest year is bold and stays in view beside the party column while earlier years scroll; each year's winner is bold on a 30% tint of its colour.
  • Tiles: #F8F8F7, 5px corners, 14px bold figures, one dark grey bar colour.
  • All sizes are rem, so panels grow with the reader's browser text size. Hairlines and stripes stay in px.

Logo

The ballot cross is the white space between the four chevrons. The logo colours are fixed brand colours and are deliberately not linked to the party palette, so data colours can change without changing the logo.
